# Security reporting

Please report suspected vulnerabilities through GitHub's private vulnerability reporting for this repository:

<https://github.com/suhasaitham22/veriq/security/advisories/new>

Do not disclose customer data, invitation/recovery/TOTP secrets, credentials, or exploit details in a public issue. The private advisory channel is enabled for this repository and is the appropriate route for sensitive reports.

Use [GitHub Issues](https://github.com/suhasaitham22/veriq/issues) only for non-sensitive product bugs and documentation problems. Do not include confidential workspace content there.
