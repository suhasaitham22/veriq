Trust boundary

Evidence, not an accuracy guarantee

Veriq checks the active, approved policy set for the workspace; it does not ask reviewers to silently choose a partial subset. Exact quotes and source versions are provenance, not independent semantic or account-action verification.

Privacy by scope

Know what is shared and processed

Workspace members can read shared policies, reviews and chat history. Policy text, drafts and chat questions sent for AI processing are sent to Cloudflare Workers AI. Veriq does not access customer account records, fetch links, or send messages. Use approved, redacted material for a supervised pilot.

Data controls

Export, retain, or delete deliberately

Owners can export workspace records in bounded pages, opt into 7–365 day review/chat/feedback retention, purge retained records, or delete a workspace after password reauthentication. Existing history is preserved until retention is enabled. These controls are product behavior, not a legal retention or compliance guarantee.

Operating limits

Designed for verified Free-plan operation

Workers AI is gated until the operator confirms the existing Cloudflare Workers Free plan. Provider limits can pause AI; there is no paid fallback. Hosted media storage is disabled. Human review remains required before sending.

Support and readiness

Start narrow and measure

Report non-sensitive product issues through GitHub issues. Use the repository’s private vulnerability report for security details; do not post customer data or secrets. Wider or enterprise use remains conditional on verified identity, operator recovery, data-lifecycle obligations and an independently reviewed benchmark.
